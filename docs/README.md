# Project documents

This folder contains the main narrative and governance documents for the TryHackMe vulnerability assessment.

## Contents

- [Executive_Risk_Memo.md](Executive_Risk_Memo.md) — executive risk summary and recommended actions
- [FINDINGS.md](FINDINGS.md) — detailed findings analysis and validation logic

## Relationship to the project

These documents are intended to convert raw scan output into a business-facing governance package. The risk memo focuses on management decisions; the findings file focuses on technical evidence, business consequence, and treatment planning.

The primary POA&M workbook remains in the repository root as `Project_1_Vulnerability_Risk_POAM.xlsx` so the project package remains easy to review in a single location.
